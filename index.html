02. Core Devices & Tech Badges

Hardware & Telecom Stack

pfSense Firewall

Central Security Appliance

Manages multi-WAN gateway routing, stateful packet filtering, NAT translation, and automated WAN gateway failover groups.

MikroTik hEX GR3

Central Router (RouterOS)

Handles Gigabit inter-VLAN routing, core bandwidth allocation, trunk connections, and static ARP table enforcement.

PLDT Home Fiber

HS Primary ISP (192.168.0.0/24)

High-speed primary fiber connection allocated to Tiguion National High School computer laboratory and administrative staff.

PLDT Enterprise

Elem Primary ISP (192.168.0.0/24)

Dedicated enterprise fiber link feeding Tiguion Elementary School's open area and staff laptops with guaranteed SLA.

Starlink Gen 2

Shared Backup ISP (192.168.100.0/24)

Low-Earth orbit satellite uplink providing zero-downtime redundant fallback for both campuses during terrestrial outages.

Ubiquiti / TP-Link APs

Managed Wireless Network

Strategic deployment across Hallway, Front, and Back areas with SSIDs mapped directly to target VLANs.

03. Key Architectural Features

Network System Capabilities

ISP Failover

Automatic multi-WAN gateway monitoring via pfSense. Instantly shifts traffic to Starlink backup when PLDT Home Fiber or Enterprise connections drop.

Firewall Protection

Centralized stateful inspection filtering, strict inbound rules, NAT isolation, and malicious packet dropping powered by pfSense.

Centralized Management

Single point routing and switch administration via MikroTik hEX GR3, simplifying configuration updates and bandwidth queues.

Network Segmentation

802.1Q VLAN tagging separating student computer labs, administrative staff, faculty members, and guest wireless users.

Scalable Architecture Design

Structured subnetting scheme equipped with room for additional switch stacks, extended wireless coverage, and future inter-campus fiber link upgrades without network restructuring.
